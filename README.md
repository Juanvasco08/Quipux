# Quipux
Nosotros nos apoyamos con Gemini IA y utilizamos Visual Studio Code para ejecutarlo. El programa es un sistema de gestión académica para la UCO, donde su función principal es calcular la nota final (promedio) en una materia. Para esto, utilizamos los pilares de la Programación Orientada a Objetos (POO).

Su estructura lógica parte de la creación de la clase base llamada Persona.java, la cual es la encargada de definir los modelos y atributos del programa en sí. Esta cuenta con dos subclases que la heredan para compartir distintas variables, como el nombre y la cédula; estas subclases son Estudiante.java y Profesor.java. Además, se tiene otro archivo llamado Main.java, el cual es el encargado de coordinar la interacción de las clases y registrar una cantidad N de notas del estudiante. La idea final de este programa es indicarle a la persona su resultado: si su promedio es mayor o igual a 0.0 y menor a 3.0, no aprobó la materia; pero si su promedio es mayor o igual a 3.0 y menor o igual a 5.0, aprobó la materia, generando así el boletín final de cada estudiante.

Para el desarrollo de este programa se utilizaron distintos conceptos de POO, como por ejemplo, hay presencia de abstracción en la clase Persona.java, la cual es la encargada de las variables nombre y cédula; también utilizamos el encapsulamiento, haciendo que estas variables sean private; por otro lado, implementamos la herencia en Estudiante.java y Profesor.java usando los comandos extends y super(); utilizamos ArrayList para manejar la lista de notas y permitir la interacción con el objeto profesor dentro del Main.java; y finalmente, aplicamos el concepto de métodos en la clase Estudiante, pues estos son los encargados de listar las calificaciones, calcular el promedio y así determinar si se aprueba o no la materia.
